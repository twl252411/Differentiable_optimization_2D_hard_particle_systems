# Differentiable optimization for periodic hard-particle RVEs

This repository accompanies the manuscript **“Differentiable constrained
optimization of periodic hard-particle systems with prescribed spatial
statistics.”** It provides the two-stage differentiable optimizer, image-based
reference extraction, final numerical data used in the manuscript, plotting
programs for Figures 2–11, and Abaqus helper scripts for downstream finite
element analysis.

## Main capabilities

The optimizer generates two-dimensional periodic monodisperse particle RVEs by
matching complementary spatial descriptors while enforcing periodic
hard-particle feasibility. The implemented descriptors include:

- radial distribution function (RDF);
- anisotropic radial distribution function (ARDF);
- nearest-neighbor distance distribution (NND);
- Voronoi-area distribution and coefficient of variation;
- coordination-number distribution and mean coordination;
- overlap and minimum-gap measures under periodic boundary conditions.

The final exported configuration is the terminal **Stage-2** configuration.
There is no separate Stage 3.

## Reproducibility scope

The repository contains the code and data needed to inspect the
method, reported statistics, and manuscript plots.

- Figure 2 contains 50 final benchmark records: two references, five methods,
  and five paired seeds.
- Figure 3 reports mean ± one sample standard deviation for 20 attempts in each
  target/initialization group. Acceptance counts are supplied separately.
- Figures 4 and 5 use representative optimization histories and
  configurations.
- Figures 6–11 use ten-sample descriptor data for the image-based
  and numerical references.
- Tables 1 and 2 use the 120-run size-scaling aggregate in
  `manuscript_data/aggregates/size_scaling_reported.csv`. Each table row contains
  ten accepted runs and reports the success rate.

Figures 1, C.1, D.1, E.1, and E.2 are included as author-supplied figure files
and are not generated by the Python plotting workflow. Elastic and nonlinear
damage source data, Abaqus databases, and run-level scratch files are excluded.
The FE scripts are included for methodological inspection, but the manuscript's
FE results cannot be regenerated from this repository alone.

## Reference cases and optimization settings

The matched image-based and numerical references use the same numerical setup:

- particle number: `N = 349`;
- square-window side length: `L = 10`;
- nominal radius: `r = 0.21681174785100282`;
- nominal particle area fraction: approximately `0.515`;
- hard-core/statistical radius: `r_h = 1.025 r`;
- identical descriptor discretization, weights, initialization controls, and
  stopping definitions.

All current differentiable studies use a Stage-2 target total loss of `1e-4`.
The matched-reference and initialization studies use maximum Stage-1/Stage-2
iteration counts of `5000/600`. The size-scaling study used `8000/12000` so that
the largest and densest cases could reach the same target.

The exported `points_final` is exactly `points_stage2`. Intermediate and
terminal overlap projections are Stage-2 operations. Descriptor losses and
feasibility measures are recomputed on the terminal coordinates. Reaching an
iteration limit alone does not imply acceptance; the saved Stage-2 metadata
records the stopping result and terminal feasibility check.

## Requirements

The core optimizer requires:

- Python 3.10 or newer;
- JAX;
- NumPy;
- SciPy;
- Matplotlib;
- PyYAML.

The optional image-detection workflow additionally requires OpenCV and
scikit-image.

The `workflows/feh_*` programs require Abaqus/CAE and must be run from an Abaqus
command environment. `workflows/feh_elastic_post.py` also requires NumPy and
OpenPyXL in the Abaqus Python environment.

## Installation

From the repository root, install the core package with:

```bash
python -m pip install -e .
```

Install the optional image dependencies with:

```bash
python -m pip install -e ".[image]"
```

Alternatively, install all dependencies listed in the requirements file:

```bash
python -m pip install -r requirements.txt
```

## Running the optimizer

Run the matched numerical-reference configuration with:

```bash
python -m cli --config configs/default_2d.yaml
```

Run the image-derived reference configuration with:

```bash
python -m cli --config configs/from_detected_fibers.yaml
```

After installation, the equivalent console entry point is:

```bash
mathrve --config configs/default_2d.yaml
```

Use `--output-dir` to select an output directory and `--num-samples` to control
the number of generated RVEs. Generated results should remain under `outputs/`
or another ignored directory.

## Image-reference extraction

The supplied micrograph and detected normalized centers are under
`image_detection/`. Inspect the available segmentation options with:

```bash
python image_detection/image_detection.py --help
```

The matched-reference manuscript analysis represents the detected particles by
their mean radius because the optimizer is monodisperse.

## Regenerating manuscript figures

Regenerate Figures 2–11 from the supplied final data with:

```bash
python figures/make_all_figures.py
```

The command writes PNG, PDF, and SVG outputs beside each plotting program. It
only redraws the figures; it does not rerun the optimization campaigns.
Individual figure programs can also be executed directly, for example:

```bash
python figures/Figure-3/make_initialization_sensitivity_20.py
python figures/Figure-4/make_convergence.py
```

## Cell-list acceleration

Stage 1, periodic overlap projections, and exact periodic feasibility checks
use a two-dimensional periodic cell list for systems with at least 512
particles. Smaller systems use the dense NumPy implementation because cell
construction costs more than the corresponding short all-pairs calculation.
Pair indices are sorted before projection updates to retain deterministic update
order.

The differentiable Stage-2 RDF, ARDF, NND, Voronoi, coordination, and overlap
losses retain their JAX all-pairs or grid formulations. The cell list therefore
accelerates short-range geometric operations without changing the descriptor
formulation. The runtimes reported in Tables 1 and 2 were measured with this
adaptive implementation.

## Abaqus helper workflows

The supplied Abaqus scripts are:

- `workflows/generate_rve.py`;
- `workflows/feh_elastic_pre.py`;
- `workflows/feh_elastic_post.py`;
- `workflows/feh_damage_periodic_mesh.py`;
- `workflows/feh_damage_pre.py`;
- `workflows/feh_damage_post.py`.

`generate_rve.py` loads its inputs from `configs/` and creates size-tagged NPZ
files and companion CAE models. Abaqus-generated files such as CAE, ODB, DAT,
MSG, STA, and lock files are excluded through `.gitignore`.
